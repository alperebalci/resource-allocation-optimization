# Adversarial and Game-Theoretic Optimization

This project adds an explicit attacker-defender and strategic-interaction track to the resource-allocation portfolio. It focuses on prescriptive decisions made against a strategic best response rather than against passive uncertainty alone.

## Included models

### 1. Stackelberg security allocation

The defender commits limited protection resources across targets. The attacker observes the commitment and chooses the target with the largest remaining expected loss.

The zero-sum model is:

```text
minimize z

subject to
loss_i * (1 - coverage_i) <= z       for every target i
sum_i coverage_i <= resource_budget
0 <= coverage_i <= 1
```

The result is a committed leader strategy, the attacker's best response, and the resulting worst expected loss.

### 2. Network interdiction

A strategic attacker removes up to `B` directed edges to maximize the defender's shortest-path length.

The implementation enumerates interdiction sets and is therefore exact for small networks. This makes it useful for teaching, regression tests, and validating larger decomposition or bilevel implementations.

The model is deliberately scoped to small instances; large-scale interdiction normally requires mixed-integer reformulations, decomposition, or specialized bilevel methods.

### 3. Robust adversarial resource allocation

Resources are allocated before an adversary selects one demand-shock scenario. The model minimizes worst-case weighted unmet demand:

```text
minimize z

subject to
sum_i x_i <= total_units
u_s,i >= demand_s,i - x_i
z >= sum_i weight_i * u_s,i       for every scenario s
x_i integer, u_s,i >= 0
```

This is a finite-scenario minimax MILP. It provides a bridge between robust optimization and explicit attacker-defender reasoning.

## Why this belongs in prescriptive analytics

Classical stochastic optimization assumes uncertainty is generated by a probability model. Game-theoretic and adversarial optimization instead models another decision-maker whose action depends on our policy.

That distinction matters in security, competitive allocation, market design, cyber-physical systems, network protection, inspection planning, and resilient operations.

## Dependencies

The implementation uses NumPy and SciPy only.

## Scope and limitations

- The Stackelberg example is zero-sum and uses fractional coverage.
- The interdiction implementation is exact enumeration and is not intended for large graphs.
- The robust allocation model uses a finite scenario set rather than an endogenous continuous adversary.
- These are transparent reference implementations, not operational security recommendations.
